# ZVERTURET

Музыкальный плеер на Next.js и React с демо-записями, треками из актуального чарта 2026 года и подборкой фонка.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Возможности

- Шесть потоковых демо-треков электронной музыки и техно доступны сразу после открытия приложения.
- Треки 2026 года и фонк загружаются из музыкального чарта и каталога; для прослушивания доступны MP3-превью.
- Фильтры по жанрам, поиск по библиотеке и очередь треков.
- Обложки в библиотеке и на экране плеера отображаются в чёрно-белом виде.
- Воспроизведение, пауза, переход между треками и перемотка.
- Регулировка громкости.
- Адаптивный интерфейс для мобильных и настольных экранов.
- Мерцающий монохромный фон с движущимися бликами по сторонам; анимация усиливается при воспроизведении и изменении громкости.
- Векторный логотип-пластинка и минималистичный чёрно-белый интерфейс.
- Концептуальные ZVERTURET Pro и Pro+ с описанием будущих преимуществ. Подписки и перечисленные premium-функции пока не реализованы.
- Страница подписок доступна отдельно по адресу `/plans`.

## Структура

```text
app/                         Маршрут, общий layout и стили
src/
  entities/track/             Тип трека и форматирование времени
  features/charts/            Загрузка музыкальных подборок
  features/playback/          Состояние и управление аудиоплеером
  widgets/music-player/       Сборка интерфейса плеера
```

Демо-аудио загружается с SoundHelix, а актуальные подборки и MP3-превью — из Deezer; для воспроизведения требуется подключение к интернету. У превью ограниченная длительность.
